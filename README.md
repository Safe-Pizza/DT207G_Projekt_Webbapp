# Projektuppgift DT207G, Webbplats
Detta är en projektuppgift i _Webbutveckingsprogrammet_ på Mittuniveristetet.

## Redovsning
[Webbplats](https://safe-pizza.github.io/DT207G_Projekt_Webbapp/)

## Uppgift
Denna del av projeketuppgiften går ut på att skapa en webbplats som konsumerar en REST-webbtjänst samt har ett admingränssnitt som är skyddat bakom inloggning.

## Lösning
Här kan du läsa om vilka sidor och funktioner som finns:

### Sidor
* **index.html:** Startsida med information om sidan,
* **menu.html:** Restaurangens meny i textformat,
* **table.html:** Bordbokning via formulär,
* **contact.html:** Kontaktsida med kontaktformulär,
* **order.html:** Menysida för beställning av mat,
* **allergy.html:** Allergiingormation,
* **login.html:** Formulär för att logga in användare via webbtjänst för access till adminsida,
* **admin.html:** Adminsida vid inloggad användare, hanterar restaurangens meny.

### Funktioner
* **Logga in användare:** Användare kan logga in via login-sida,
* **Se menyn:** Menyn kan ses i olika format på menu.html, order.html och admin.html,
* **Lägg till i meny:** Rätt kan läggas till i menyn via formulär på adminsidan i inloggat läge,
* **Ta bort från meny:** Rätt kan tas bort via knapp på adminsidan i inloggat läge,
* **Ändra i befintlig meny:** Rätt kan ändras via knapp och formulär på adminsidan i inloggat läge,
* **Validering:** Inputfälten valideras, fälten får ej vara tomma.

### Har används för uppgiften
* HTML
* CSS
* JavaScript
* Vite
